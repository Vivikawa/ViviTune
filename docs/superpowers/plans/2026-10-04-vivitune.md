# ViviTune Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows-программа: один раз вводишь SOCKS5-прокси, выбираешь `.exe`, и весь TCP/UDP этих приложений идёт через прокси.

**Architecture:** WinForms-обёртка над `sing-box.exe` (TUN + правило `process_name` → `socks` outbound). Программа генерирует `config.json`, предварительно проверяет прокси (TCP, SOCKS5, UDP ASSOCIATE), запускает sing-box внутри Job Object и показывает его лог.

**Tech Stack:** C# 7.3, .NET Framework 4.8 (WinForms, `JavaScriptSerializer` из `System.Web.Extensions`), sing-box 1.12.12. Сторонних NuGet-пакетов нет.

**Spec:** `docs/superpowers/specs/2026-10-04-vivitune-design.md`

## Global Constraints

- Версия sing-box зафиксирована: **1.12.12** (формат DNS `type: udp`/`type: local`, `route.default_domain_resolver`).
- Таргет: `net48`, без внешних NuGet-зависимостей, без тестовых фреймворков (консольный проект с `Check`).
- Манифест: `requireAdministrator`.
- Прокси без логина и пароля (SOCKS5, метод `0x00`).
- Сопоставление приложений по имени файла (`process_name`), не по полному пути.
- YAGNI: нет профилей, трея, автозапуска, логина/пароля прокси, доменных правил, автообновления sing-box.
- В проекте нет git: шагов `commit` в плане нет. Если git будет инициализирован, коммитить после каждой задачи.
- Для всех шагов путь корня: `D:\backup\Downloads\ViviTune`; исходники в `src\`.

## Review Focus

1. **Пустой список приложений.** Правило `process_name: []` без условий матчит весь трафик и отправит всю систему в прокси. `ConfigBuilder.Build` обязан бросать исключение (тест в Task 2), UI не даёт нажать «Старт» (Task 1, `Validate`).
2. **Дубликаты и «служебные» имена.** `Chrome.exe` и `chrome.EXE` из разных папок сливаются в одно имя; `sing-box.exe` в списке игнорируется, иначе трафик самого sing-box зациклится (тест в Task 1).
3. **Битый или отсутствующий `settings.json`.** Программа должна стартовать с настройками по умолчанию, а не падать (тест в Task 1).
4. **Прокси не SOCKS5, закрытый порт, нет UDP.** Проверка возвращает понятный результат, не зависает и не бросает исключение (тесты с фейковым сервером в Task 3).
5. **Имена с кириллицей и пробелами в пути, IPv6-адрес прокси.** Конфиг остаётся валидным JSON, исключение прокси получает `/128` (тесты в Task 2). После «Стоп» и после убийства программы интернет в системе должен работать (ручная проверка в Task 5).

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Net;
using System.Web.Script.Serialization;

namespace ViviTune
{
    public class Settings
    {
        public string Ip = "192.168.1.1";
        public int Port = 1818;
        public List<string> Apps = new List<string>();

        public static Settings Load(string path)
        {
            try { return new JavaScriptSerializer().Deserialize<Settings>(File.ReadAllText(path)) ?? new Settings(); }
            catch { return new Settings(); } // ponytail: нет файла или он битый: молча берём значения по умолчанию
        }

        public void Save(string path)
        {
            File.WriteAllText(path, new JavaScriptSerializer().Serialize(this));
        }

        // null, если всё корректно; иначе текст ошибки для пользователя
        public string Validate()
        {
            IPAddress ip;
            if (!IPAddress.TryParse(Ip, out ip)) return "Некорректный IP";
            if (Port < 1 || Port > 65535) return "Порт должен быть от 1 до 65535";
            if (ProcessNames().Count == 0) return "Добавьте хотя бы одно приложение";
            return null;
        }

        // Имена .exe для правил sing-box: без путей, без дублей, без самого sing-box.
        public List<string> ProcessNames()
        {
            var result = new List<string>();
            foreach (var path in Apps ?? new List<string>())
            {
                string name;
                try { name = Path.GetFileName(path); }
                catch (ArgumentException) { continue; } // недопустимые символы в пути
                if (string.IsNullOrEmpty(name)) continue;
                if (name.Equals("sing-box.exe", StringComparison.OrdinalIgnoreCase)) continue;
                if (result.Any(n => n.Equals(name, StringComparison.OrdinalIgnoreCase))) continue;
                result.Add(name);
            }
            return result;
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Net;
using System.Net.Sockets;
using System.Web.Script.Serialization;

namespace ViviTune
{
    public static class ConfigBuilder
    {
        static Dictionary<string, object> D(params object[] kv)
        {
            var d = new Dictionary<string, object>();
            for (int i = 0; i < kv.Length; i += 2) d[(string)kv[i]] = kv[i + 1];
            return d;
        }

        public static string Build(Settings s)
        {
            var err = s.Validate();
            if (err != null) throw new InvalidOperationException(err);

            var names = s.ProcessNames().ToArray();
            var ip = IPAddress.Parse(s.Ip);
            var cidr = ip + (ip.AddressFamily == AddressFamily.InterNetworkV6 ? "/128" : "/32");

            var config = D(
                "log", D("level", "info", "timestamp", true),
                "dns", D(
                    "servers", new object[]
                    {
                        D("type", "local", "tag", "local"),
                        D("type", "udp", "tag", "proxy-dns", "server", "1.1.1.1", "detour", "proxy")
                    },
                    "rules", new object[] { D("process_name", names, "server", "proxy-dns") }),
                "inbounds", new object[]
                {
                    D("type", "tun", "tag", "tun-in", "address", new object[] { "172.19.0.1/30" }, "auto_route", true, "strict_route", false)
                },
                "outbounds", new object[]
                {
                    D("type", "socks", "tag", "proxy", "server", ip.ToString(), "server_port", s.Port, "version", "5"),
                    D("type", "direct", "tag", "direct")
                },
                "route", D(
                    "rules", new object[]
                    {
                        D("action", "sniff"),
                        D("protocol", "dns", "action", "hijack-dns"),
                        D("ip_cidr", new object[] { cidr }, "outbound", "direct"),
                        D("process_name", names, "outbound", "proxy")
                    },
                    "final", "direct",
                    "auto_detect_interface", true,
                    "default_domain_resolver", "local"));

            return new JavaScriptSerializer().Serialize(config);
        }
    }
}
```

```csharp
    static int FakeServer(byte[] methodReply, byte[] udpReply)
    {
        var l = new TcpListener(IPAddress.Loopback, 0);
        l.Start();
        Task.Run(() =>
        {
            using (var c = l.AcceptTcpClient())
            {
                var st = c.GetStream();
                var buf = new byte[16];
                st.Read(buf, 0, 3);
                st.Write(methodReply, 0, methodReply.Length);
                if (udpReply == null) return;
                st.Read(buf, 0, 10);
                st.Write(udpReply, 0, udpReply.Length);
            }
            l.Stop();
        });
        return ((IPEndPoint)l.LocalEndpoint).Port;
    }

    static void ProbeTests()
    {
        var ok = new byte[] { 5, 0, 0, 1, 0, 0, 0, 0, 0, 0 };
        var r = ProxyProbe.Probe("127.0.0.1", FakeServer(new byte[] { 5, 0 }, ok));
        Check(r.Reachable && r.UdpSupported, "Probe: SOCKS5 с UDP");

        var noUdp = new byte[] { 5, 7, 0, 1, 0, 0, 0, 0, 0, 0 };
        r = ProxyProbe.Probe("127.0.0.1", FakeServer(new byte[] { 5, 0 }, noUdp));
        Check(r.Reachable && !r.UdpSupported, "Probe: SOCKS5 без UDP");

        r = ProxyProbe.Probe("127.0.0.1", FakeServer(new byte[] { 0x48, 0x54 }, null));
```

```csharp
using System;
using System.IO;
using System.Net.Sockets;

namespace ViviTune
{
    public class ProbeResult
    {
        public bool Reachable;
        public bool UdpSupported;
        public string Error;
    }

    public static class ProxyProbe
    {
        public static ProbeResult Probe(string ip, int port, int timeoutMs = 3000)
        {
            var r = new ProbeResult();
            try
            {
                using (var c = new TcpClient())
                {
                    if (!c.ConnectAsync(ip, port).Wait(timeoutMs)) { r.Error = "таймаут подключения"; return r; }
                    c.ReceiveTimeout = c.SendTimeout = timeoutMs;
                    var st = c.GetStream();

                    st.Write(new byte[] { 5, 1, 0 }, 0, 3); // SOCKS5, один метод: без авторизации
                    var rep = ReadN(st, 2);
                    if (rep[0] != 5 || rep[1] != 0) { r.Error = "это не SOCKS5 без авторизации"; return r; }
                    r.Reachable = true;

                    st.Write(new byte[] { 5, 3, 0, 1, 0, 0, 0, 0, 0, 0 }, 0, 10); // UDP ASSOCIATE 0.0.0.0:0
                    var u = ReadN(st, 4); // VER REP RSV ATYP
                    r.UdpSupported = u[0] == 5 && u[1] == 0;
                }
            }
            catch (Exception e)
            {
                if (!r.Reachable) r.Error = e.GetBaseException().Message; // ошибка после рукопожатия = просто нет UDP
            }
            return r;
        }

        static byte[] ReadN(Stream s, int n)
        {
            var b = new byte[n];
            int o = 0;
            while (o < n)
            {
                int k = s.Read(b, o, n - o);
                if (k == 0) throw new IOException("соединение закрыто");
                o += k;
            }
            return b;
        }
    }
}
```

`src/ViviTune/Runner.cs`:

```csharp
using System;
using System.Diagnostics;
using System.IO;
using System.Runtime.InteropServices;

namespace ViviTune
{
    public class Runner : IDisposable
    {
        readonly string _exe;
        readonly IntPtr _job;
        Process _p;

        public event Action<string> Line;
        public event Action Exited;

        public bool Running { get { return _p != null && !_p.HasExited; } }

        public Runner(string singBoxExe)
        {
            _exe = singBoxExe;
            _job = CreateJob();
        }

        public void Start(string configPath)
        {
            var psi = new ProcessStartInfo(_exe, "run -c \"" + configPath + "\"")
            {
                UseShellExecute = false,
                CreateNoWindow = true,
                RedirectStandardOutput = true,
                RedirectStandardError = true,
                WorkingDirectory = Path.GetDirectoryName(configPath)
            };
            var p = new Process { StartInfo = psi, EnableRaisingEvents = true };
            DataReceivedEventHandler onLine = (s, e) => { if (e.Data != null) Raise(Line, e.Data); };
            p.OutputDataReceived += onLine;
            p.ErrorDataReceived += onLine;
            p.Exited += (s, e) => { var h = Exited; if (h != null) h(); };
            p.Start();
            AssignProcessToJobObject(_job, p.Handle); // sing-box умрёт вместе с нами, даже если нас убьют
            p.BeginOutputReadLine();
            p.BeginErrorReadLine();
            _p = p;
        }

        public void Stop()
        {
            if (!Running) return;
            try { _p.Kill(); _p.WaitForExit(3000); } catch (InvalidOperationException) { } // уже завершился
        }

        public void Dispose()
        {
            Stop();
            CloseHandle(_job); // KILL_ON_JOB_CLOSE
        }

        static void Raise(Action<string> h, string s) { if (h != null) h(s); }

        static IntPtr CreateJob()
        {
            var job = CreateJobObject(IntPtr.Zero, null);
            var info = new JOBOBJECT_EXTENDED_LIMIT_INFORMATION();
            info.BasicLimitInformation.LimitFlags = 0x2000; // JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE
            int size = Marshal.SizeOf(typeof(JOBOBJECT_EXTENDED_LIMIT_INFORMATION));
            IntPtr ptr = Marshal.AllocHGlobal(size);
            try
            {
                Marshal.StructureToPtr(info, ptr, false);
                SetInformationJobObject(job, 9, ptr, (uint)size); // JobObjectExtendedLimitInformation
            }
            finally { Marshal.FreeHGlobal(ptr); }
            return job;
        }

        [DllImport("kernel32.dll", CharSet = CharSet.Unicode)]
        static extern IntPtr CreateJobObject(IntPtr attrs, string name);
        [DllImport("kernel32.dll")]
        static extern bool SetInformationJobObject(IntPtr job, int infoClass, IntPtr info, uint size);
        [DllImport("kernel32.dll")]
        static extern bool AssignProcessToJobObject(IntPtr job, IntPtr process);
        [DllImport("kernel32.dll")]
        static extern bool CloseHandle(IntPtr h);

        [StructLayout(LayoutKind.Sequential)]
        struct JOBOBJECT_BASIC_LIMIT_INFORMATION
        {
            public long PerProcessUserTimeLimit;
            public long PerJobUserTimeLimit;
            public uint LimitFlags;
            public UIntPtr MinimumWorkingSetSize;
            public UIntPtr MaximumWorkingSetSize;
            public uint ActiveProcessLimit;
            public UIntPtr Affinity;
            public uint PriorityClass;
            public uint SchedulingClass;
        }

        [StructLayout(LayoutKind.Sequential)]
        struct IO_COUNTERS
        {
            public ulong ReadOperationCount, WriteOperationCount, OtherOperationCount;
            public ulong ReadTransferCount, WriteTransferCount, OtherTransferCount;
        }

        [StructLayout(LayoutKind.Sequential)]
        struct JOBOBJECT_EXTENDED_LIMIT_INFORMATION
        {
            public JOBOBJECT_BASIC_LIMIT_INFORMATION BasicLimitInformation;
            public IO_COUNTERS IoCounters;
            public UIntPtr ProcessMemoryLimit;
            public UIntPtr JobMemoryLimit;
            public UIntPtr PeakProcessMemoryUsed;
            public UIntPtr PeakJobMemoryUsed;
```

`src/ViviTune/MainForm.cs`:

```csharp
using System;
using System.Drawing;
using System.IO;
using System.Threading.Tasks;
using System.Windows.Forms;

namespace ViviTune
{
    public class MainForm : Form
    {
        static readonly string Dir = AppDomain.CurrentDomain.BaseDirectory;
        static readonly string SettingsPath = Path.Combine(Dir, "settings.json");
        static readonly string ConfigPath = Path.Combine(Dir, "config.json");
        static readonly string SingBox = Path.Combine(Dir, "sing-box.exe");

        readonly Settings _s = Settings.Load(SettingsPath);
        readonly Runner _runner = new Runner(SingBox);
        readonly TextBox _ip = new TextBox { Bounds = new Rectangle(130, 12, 150, 23) };
        readonly NumericUpDown _port = new NumericUpDown { Bounds = new Rectangle(290, 12, 80, 23), Minimum = 1, Maximum = 65535 };
        readonly ListBox _apps = new ListBox { Bounds = new Rectangle(12, 70, 380, 150), IntegralHeight = false };
        readonly Button _add = new Button { Text = "Добавить…", Bounds = new Rectangle(400, 70, 100, 28) };
        readonly Button _remove = new Button { Text = "Удалить", Bounds = new Rectangle(400, 104, 100, 28) };
        readonly Button _toggle = new Button { Text = "Старт", Bounds = new Rectangle(12, 232, 488, 36) };
        readonly Label _status = new Label { Bounds = new Rectangle(12, 276, 488, 20) };
        readonly TextBox _log = new TextBox { Bounds = new Rectangle(12, 302, 488, 216), Multiline = true, ReadOnly = true, ScrollBars = ScrollBars.Vertical };

        public MainForm()
        {
            Text = "ViviTune";
            ClientSize = new Size(512, 530);
            FormBorderStyle = FormBorderStyle.FixedSingle;
            MaximizeBox = false;

            Controls.Add(new Label { Text = "Прокси SOCKS5:", Bounds = new Rectangle(12, 15, 115, 20) });
            Controls.Add(new Label { Text = ":", Bounds = new Rectangle(282, 15, 8, 20) });
            Controls.Add(new Label { Text = "Приложения:", Bounds = new Rectangle(12, 50, 200, 18) });
            Controls.AddRange(new Control[] { _ip, _port, _apps, _add, _remove, _toggle, _status, _log });

            _ip.Text = _s.Ip;
            _port.Value = Math.Max(1, Math.Min(65535, _s.Port));
            foreach (var a in _s.Apps ?? new System.Collections.Generic.List<string>()) _apps.Items.Add(a);

            _ip.TextChanged += (a, b) => Changed();
            _port.ValueChanged += (a, b) => Changed();
            _add.Click += (a, b) =>
            {
                using (var d = new OpenFileDialog { Filter = "Программы (*.exe)|*.exe" })
                    if (d.ShowDialog() == DialogResult.OK) { _apps.Items.Add(d.FileName); Changed(); }
            };
            _remove.Click += (a, b) =>
            {
                if (_apps.SelectedIndex >= 0) { _apps.Items.RemoveAt(_apps.SelectedIndex); Changed(); }
            };
            _toggle.Click += (a, b) => Toggle();
            _runner.Line += l => UI(() => Log(l));
            _runner.Exited += () => UI(() => { Log("sing-box завершился"); SetRunning(false); });
            FormClosing += (a, b) => _runner.Dispose();

            Changed();
        }

        void UI(Action a) { if (IsHandleCreated && !IsDisposed) BeginInvoke(a); }

        void Log(string line) { _log.AppendText(line + Environment.NewLine); }

        // Копирует поля в настройки, сохраняет, обновляет доступность кнопки и статус.
        void Changed()
        {
            _s.Ip = _ip.Text.Trim();
            _s.Port = (int)_port.Value;
            _s.Apps = new System.Collections.Generic.List<string>();
            foreach (var a in _apps.Items) _s.Apps.Add((string)a);
            _s.Save(SettingsPath);

            var err = _s.Validate();
            _toggle.Enabled = _runner.Running || err == null;
            _status.Text = err ?? (_runner.Running ? "Работает" : "Готово");
        }

        void SetRunning(bool running)
        {
            _ip.Enabled = _port.Enabled = _add.Enabled = _remove.Enabled = !running;
            _toggle.Text = running ? "Стоп" : "Старт";
            Changed();
        }

        void Toggle()
        {
            if (_runner.Running) { _runner.Stop(); return; } // событие Exited вернёт интерфейс в исходное состояние
            if (!File.Exists(SingBox)) { _status.Text = "Не найден sing-box.exe рядом с программой"; return; }

            _toggle.Enabled = false;
            _status.Text = "Проверяю прокси…";
            string ip = _s.Ip;
            int port = _s.Port;
            Task.Run(() => ProxyProbe.Probe(ip, port)).ContinueWith(t => UI(() => OnProbed(t.Result)));
        }

        void OnProbed(ProbeResult r)
        {
            if (!r.Reachable) { _status.Text = "Прокси недоступен: " + r.Error; _toggle.Enabled = true; return; }
            if (!r.UdpSupported) Log("ВНИМАНИЕ: UDP через этот прокси не работает: игры и голосовая связь могут не заработать.");
            try
            {
                File.WriteAllText(ConfigPath, ConfigBuilder.Build(_s));
                _runner.Start(ConfigPath);
                SetRunning(true);
            }
            catch (Exception e)
            {
                _status.Text = "Не удалось запустить: " + e.Message;
                _toggle.Enabled = true;
            }
        }
    }
}
```
